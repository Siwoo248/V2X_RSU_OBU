# V2X RSU & OBU 고속 주행 지능형 V2X 통신 시스템 (11.23)

RSU(Roadside Unit, 노변 기지국 서버)와 2대의 독립된 OBU(On-Board Unit, 차량 단말기) 간 소켓 통신을 통해 **실시간 고속 주행(60~70m/s) 환경에서 물리적 차간거리를 반영한 자율 추월(50m), 긴급 차선 회피(200m), 연쇄 충돌(100m) 알고리즘**을 구현하고, 터미널 콘솔에 **24-bit TrueColor 픽셀 그래픽**으로 시각화한 프로젝트입니다.

## 🛣️ 24-bit TrueColor 픽셀 그래픽 렌더링 엔진

단순한 텍스트 기호(`-`, `_`) 대신, 터미널 **유니코드 하프블록(`▀`)과 24비트 RGB TrueColor**를 결합하여 터미널 콘솔 화면 안에 실제 픽셀 단위로 도로와 자동차를 렌더링합니다:

* **아스팔트 노면**: 다크 아스팔트 그레이 (`RGB: 38, 44, 54`)
* **중앙 차선**: 선명한 고속도로 황색 점선 (`RGB: 250, 204, 21`)
* **상/하단 가드레일**: 메탈릭 실버 그레이 (`RGB: 90, 100, 115`)
* **픽셀 자동차 스프라이트 (8x3 픽셀)**:
  * 고무 바퀴(`RGB: 15, 15, 15`), 유리창(`RGB: 140, 210, 255`), 전방 헤드라이트 광선
  * 앞차(`CAR01`): 에메랄드 그린 픽셀카
  * 뒤차(`CAR02`): 스카이 블루 픽셀카 (추월/회피 시 오렌지색으로 전환)
  * 사고 차량: 붉은 차체 및 번쩍이는 불꽃 픽셀(`💥`) 이펙트

## 🧠 지능형 고속 주행 물리 알고리즘

고속도로 고속 주행(60~70m/s) 환경의 제동 거리 및 반응 시간을 고려한 4단계 의사결정 시스템입니다:

```
[CAR02 뒤차 주행 흐름도]

           거리 > 200m
           ┌───────────────────────────────────────────────┐
           │ 1. 원거리 주의 경고: 차선 변경 없이 1차로 유지 │
           └───────────────────────────────────────────────┘
                                   │
                           100m < 거리 ≤ 200m
                                   ▼
           ┌───────────────────────────────────────────────┐
           │ 2. 긴급 차선 회피: 2차로로 긴급 변경 & 감속(35m/s) │
           └───────────────────────────────────────────────┘
                                   │
                               거리 ≤ 100m
                                   ▼
           ┌───────────────────────────────────────────────┐
           │ 3. 연쇄 충돌 발생: 제동 거리 부족으로 추돌 정지 │
           └───────────────────────────────────────────────┘

[평상시 자율 추월 (사고 없을 때)]
           거리 ≤ 50m (뒤차가 더 빠름)
           ┌───────────────────────────────────────────────┐
           │ • 2차로(추월차로)로 변경 가속 ➜ 50m 앞지르면 1차로 복귀 │
           └───────────────────────────────────────────────┘
```

| 알고리즘 모드 | 발동 거리 조건 | 동작 설명 |
| :--- | :---: | :--- |
| **⚠️ 원거리 사고 주의** | `거리 > 200 m` | 전방 사고가 아직 멀리 있으므로, 차선을 급하게 변경하지 않고 **1차로를 유지하며 주의 안내창만 표시** |
| **🚨 긴급 차선 회피** | `100 m < 거리 ≤ 200 m` | 안전거리(200m) 이내 진입 시 **즉시 2차로로 긴급 차선 변경 및 35m/s로 안전 감속**하여 사고 지점 통과 |
| **💥 연쇄 충돌 (추돌)** | `거리 ≤ 100 m` | 70m/s 고속에서 100m 이내는 제동 불가 거리 $\rightarrow$ **앞차 급사고 시 뒤차도 피하지 못하고 `연쇄 충돌` 정지** |
| **🚗 자율 추월 (Overtaking)** | `거리 ≤ 50 m` | 평상시 빠른 뒤차(70m/s)가 앞차(60m/s) 50m 뒤까지 따라붙으면 **2차로로 추월 후 50m 앞서면 1차로 복귀** |

## 🎮 시나리오별 테스트 가이드

### 시나리오 1: 원거리 경고 ➜ 안전거리(200m) 진입 시 긴급 회피
1. 터미널 3개 실행 후 2~3초 뒤 **터미널 2 (`CAR01`)**에서 **`a`** 키를 누릅니다.
2. **터미널 3 (`CAR02`)** 화면:
   - 처음에는 거리가 200m 이상이어서 `⚠️ [원거리 주의]`가 뜨며 1차로를 유지합니다.
   - 거리가 200m 이내로 좁혀지는 순간 `🚨 [긴급 회피]`로 전환되며 **2차로로 올라가 사고 차를 비껴 지나갑니다.**

### 시나리오 2: 50m 자율 추월 (평상시)
1. 아무 키도 누르지 않고 약 35~40초 동안 주행을 지켜봅니다.
2. 뒤차(70m/s)가 앞차(60m/s)와의 거리를 초당 10m씩 좁혀 **50m 이내로 접근하는 순간 자동으로 2차로(추월차로)로 변경**합니다.
3. 앞차를 추월하여 50m 이상 앞서면 **다시 1차로(주행차로)로 안전하게 복귀**합니다.

### 시나리오 3: 100m 이내 연쇄 충돌
1. 뒤차가 앞차 100m 이내(약 30~35초 주행 시점)로 바짝 붙었을 때 **터미널 2 (`CAR01`)**에서 **`a`** 키를 누릅니다.
2. 뒤차도 고속 제동 거리 부족으로 피하지 못하고 **`💥 [연쇄 충돌!]` 판정을 받으며 속도 0으로 충돌 정지**합니다.

### 시나리오 4: CAR02 단말기 자체 사고 발생
* **터미널 3 (`CAR02`)**에서도 언제든지 **`a`** 키를 누르면 즉시 사고가 발생하고 RSU로 긴급 신고가 전송됩니다.
