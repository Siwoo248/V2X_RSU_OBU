# 미니 V2X (Vehicle-to-Everything) 실습 프로그램 (agy 사용)

본 실습은 1대의 노변 기지국(RSU)과 2대의 차량(OBU) 간의 V2X 통신을 로컬 환경(127.0.0.1)에서 시뮬레이션하는 C 언어 프로그램입니다.

---

## 📁 파일 구성
- `v2x_protocol.h`: V2X 패킷 구조체(`V2XPacket`), 메시지 타입(REGISTER, BSM, DENM, ACK), 통신 유틸리티 정의
- `rsu_server.c`: RSU(노변 기지국) 서버 소스 코드 (멀티스레드 기반 클라이언트 관리 및 브로드캐스트)
- `obu.c`: OBU(차량 단말기) 소스 코드 (BSM 1초 주기 전송, 비동기 수신, 단일 키 입력 기반 DENM 전송)
- `Makefile`: 빌드 스크립트 (`rsu_server`, `obu`, `rsu_server.exe`, `obu.exe` 생성)

---

## 🎯 4단계 실습 확인 포인트

1. **1단계: 접속 및 등록**
   - CAR01, CAR02 실행 시 자동으로 RSU(`127.0.0.1:9000`)에 접속하고 차량 ID를 등록합니다.
   - [창 1] RSU 화면에 차량 등록 및 현재 접속 대수(1대, 2대)가 표시됩니다.

2. **2단계: 상태 전송 (BSM)**
   - 각 차량은 1초마다 위치(x, y)와 속도(km/h)를 RSU로 전송합니다 (`[BSM 송신]`).
   - RSU는 이를 수신하여 다른 차량에게 중계하며, 상대 차량 화면에 `[주변 BSM 수신]`으로 실시간 표시됩니다.

3. **3단계: 사고 알림 (DENM)**
   - [창 2] CAR01 창에서 키보드의 **`a` 키** (또는 **`Enter` 키**)를 누릅니다.
   - CAR01 차량의 속도가 0 km/h로 멈추며 RSU로 긴급 사고 알림(DENM)을 전송합니다.
   - [창 1] RSU 창에 긴급 사고 접수 로그가 출력되고, 전 차량으로 브로드캐스트됩니다.
   - [창 3] CAR02 창에 즉시 **`🚨 [긴급 경고 - DENM 수신!]`** 경보 박스가 뜨며, 차량이 서행 감속합니다.

4. **4단계: 단일 PC 내 3개 창 연동**
   - 외부 네트워크 연결 없이 `127.0.0.1` 루프백 인터페이스를 통해 PC 안에서 3개 프로세스가 실시간으로 연동됩니다.
