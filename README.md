# V2X RSU & OBU 통신 및 사고 회피 시스템

RSU(Roadside Unit, 서버)와 OBU(On-Board Unit, 차량 단말) 간 통신을 통해 **전방 사고를 감지하고 차선을 회피하는 시스템**입니다.

---

## 🚗 차선 회피 시각화

### 1단계: 정상 주행 (앞차 뒤를 따라가는 중)
| 차선 | 도로 상황 |
| :--- | :--- |
| **2차로 (y=200)** | `────────────────────────────────────────` *(비어있음)* |
| **1차로 (y=100)** | `─── 🚗 (내 차) ──────────▶ ─── 🚗 (앞차) ──────────▶` |

---

### 2단계: 앞차 사고 발생!
| 차선 | 도로 상황 |
| :--- | :--- |
| **2차로 (y=200)** | `────────────────────────────────────────` |
| **1차로 (y=100)** | `─── 🚗 (내 차) ──────────▶ ─── 💥 (사고 발생!)` |

> 🚨 **경고창:** 전방에 사고가 났으니 **차선(y축)을 200으로 변경**하세요!

---

### 3단계: 차선 변경 및 안전 회피
| 차선 | 도로 상황 |
| :--- | :--- |
| **2차로 (y=200)** | `──────────────── ↗️ 🚗 (2차로로 회피 주행) ──────▶` |
| **1차로 (y=100)** | `─────────────────────────────── 💥 (사고 차량 정지)` |

---

## 💻 실행 방법 (터미널 3개)

### [터미널 1] RSU 서버 실행
```bash
cd ~/c-programming/11.18
./rsu_server
```

### [터미널 2] CAR01 (앞차) 실행
```bash
cd ~/c-programming/11.18
./obu CAR01
```

### [터미널 3] CAR02 (내 차) 실행
```bash
cd ~/c-programming/11.18
./obu CAR02
```

---

## 🎮 테스트 방법

1. 터미널 3개에서 위 명령어를 차례대로 실행합니다.
2. **CAR01 (앞차)** 터미널에서 **`a`** 키를 누릅니다.
3. 앞차가 💥 사고로 멈추고, **CAR02 (내 차)** 터미널에 **경고창과 함께 차선이 2차로(y=200)로 자동 변경**되는 것을 확인합니다.
4. 종료하려면 각 터미널에서 **`q`** 키 또는 `Ctrl + C`를 누릅니다.
